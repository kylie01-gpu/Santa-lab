# 산타 홀로그램 엽서 AR

엽서를 카메라로 비추면 산타 영상이 홀로그램처럼 떠올라 재생되는 웹페이지예요.
앱 설치 없이 QR 코드만 찍으면 아이폰과 안드로이드에서 모두 작동해요.

## 폴더 구성

```
index.html      화면 (시작 버튼, 안내 문구, 자막, 끝 화면)
app.js          AR 인식 + 홀로그램 효과 코드 (보통 고칠 일 없음)
config.js       ★ 설정 파일: 영상, 자막, 링크, 홀로그램 느낌
assets/
  santa.mp4     산타 영상 (지금은 테스트 영상)
  postcard.jpg  시작 화면·미리보기용 엽서 이미지
  targets.mind  ★ 엽서 인식 파일 (직접 만들어서 넣어야 해요)
```

## 1. 엽서 인식 파일 만들기 (꼭 필요)

1. https://hiukim.github.io/mind-ar-js-doc/tools/compile 에 들어가요.
2. **엽서 원본 이미지**(인쇄하는 것과 똑같은 파일)를 올리고 **Start**를 눌러요.
3. 끝나면 **Download**로 받은 `targets.mind`를 `assets` 폴더에 넣어요.

사이트가 안 열리면 이 폴더의 **compile.html**을 PC 크롬에서 더블클릭해서 열어요. 같은 변환을 해 주고 `targets.mind`를 바로 저장해 줘요. (인터넷 연결 필요)

엽서 디자인을 바꾸면 이 파일도 다시 만들어야 해요.

## 2. 산타 영상 넣기

`assets/santa.mp4`를 실제 산타 영상으로 바꿔요. 파일 이름이 같으면 다른 곳은 고칠 필요 없어요.

- **배경은 검은색**으로 만들어요. 검은 부분이 투명하게 사라지고 산타만 빛나 보여요.
- MP4 (H.264), 720p, 10MB 이하를 추천해요. 크면 로딩이 느려져요.
- 세로 영상이든 가로 영상이든 비율에 맞춰 자동으로 조절돼요.

용량 줄이기 (ffmpeg가 있을 때):
```
ffmpeg -i 원본.mp4 -vf scale=720:-2 -c:v libx264 -crf 26 -preset veryfast -c:a aac -b:a 96k -movflags +faststart santa.mp4
```

## 3. 자막과 링크 고치기 (config.js)

- `subtitles`: 대사와 시간(초)을 영상에 맞게 고쳐요.
  CapCut 등에서 SRT 자막을 뽑았다면 `assets/santa.srt`로 넣고 `subtitlesSrt: './assets/santa.srt'`로 바꾸면 돼요.
- `storeUrl`: 스마트스토어 주소로 바꿔요. 영상이 끝나면 나오는 "문의하기" 버튼에 쓰여요.

## 4. 인터넷에 올리기 (GitHub Pages, 무료)

카메라는 **https 주소**에서만 켜져요. GitHub Pages는 자동으로 https라서 편해요.

1. github.com 가입 → 오른쪽 위 **+** → **New repository** (이름 예: `santa-lab`, Public)
2. **Add file → Upload files**로 이 폴더 안의 파일을 전부 올려요 (assets 폴더 포함).
3. **Settings → Pages** → Branch를 `main`, `/ (root)`로 고르고 **Save**
4. 1~2분 뒤 `https://아이디.github.io/santa-lab/` 주소가 생겨요.
5. 이 주소로 QR 코드를 만들어 엽서에 넣어요.

파일을 고친 뒤 다시 올리면 몇 분 안에 반영돼요. 폰에서 예전 화면이 보이면 새로고침하거나 잠시 기다려요.

## 5. 테스트하기

- **카메라 없이 효과만 보기:** 주소 끝에 `#preview`를 붙여요 (예: `…/santa-lab/#preview`). 테이블 위 엽서에서 홀로그램이 나오는 모습을 보여 주고, "엽서 놓치기" 버튼으로 화면 고정 모드도 확인할 수 있어요.
- **실제 테스트:** 엽서를 인쇄하거나 모니터에 엽서 이미지를 띄우고 폰으로 비춰요.

## 동작 방식

1. **산타 부르기** 버튼을 누르면 카메라가 켜져요. (아이폰은 이 버튼을 눌러야 소리가 나요)
2. 엽서를 비추면 엽서 위로 홀로그램이 아래에서 위로 스캔되듯 나타나며 재생돼요.
3. 재생 중에 엽서를 놓치면 0.6초 뒤 홀로그램이 화면 가운데에 고정돼서 끝까지 재생돼요. 엽서를 다시 비추면 엽서 위로 돌아가요.
4. 끝나면 **다시 보기**와 **스마트스토어 문의하기** 버튼이 나와요.
5. 오른쪽 위 🔊 버튼으로 소리를 켜고 끌 수 있어요.

## 홀로그램 느낌 조절 (config.js의 hologram)

| 항목 | 설명 | 이럴 때 |
|---|---|---|
| `tintAmount` | 0 = 원래 색, 1 = 완전 푸른 홀로그램 | 산타 옷 빨간색을 살리고 싶으면 낮추기 |
| `tint` | 홀로그램 색 | 초록빛 홀로그램: `[0.5, 1.0, 0.7]` |
| `blackCut` | 이 밝기 이하는 투명 | 검은 사각형이 비치면 0.1 정도로 올리기 |
| `brightness` | 밝기 | 밝은 방에서 흐리게 보이면 올리기 |
| `scanlines`, `flicker`, `glitch` | 줄무늬·깜빡임·지지직 | 너무 정신없으면 낮추기, 0이면 꺼짐 |
| `height` | 홀로그램 크기 (엽서 가로폭 = 1) | 더 크게 띄우고 싶으면 올리기 |
| `lift`, `offsetY` | 엽서에서 떠 있는 높이, 위아래 위치 | 위치 미세 조정 |

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| "엽서 인식 파일이 없어요" | `assets/targets.mind`가 없어요. 1번 과정으로 만들어서 넣어 주세요. |
| 카메라가 안 켜져요 | 주소가 https인지 확인해요. 카카오톡·인스타 안에서 열었다면 "다른 브라우저로 열기"로 사파리/크롬에서 열어요. 아이폰은 설정 → Safari → 카메라 → 허용. |
| 엽서를 비춰도 반응이 없어요 | 엽서 전체가 화면에 들어오게, 너무 가깝지 않게 비춰요. 어두운 곳이나 반사가 심한 코팅지는 인식이 약해요. targets.mind를 **인쇄본과 같은 이미지**로 만들었는지 확인해요. |
| 소리가 안 나요 | 아이폰 옆면 무음 스위치를 확인해요. 오른쪽 위 🔇 버튼을 눌러 소리를 켜요. |
| 영상이 늦게 나오거나 끊겨요 | 영상 용량을 줄여요 (2번의 ffmpeg 명령). |
| 홀로그램 주변에 사각형 테두리가 비쳐요 | 영상 배경이 완전한 검정이 아니에요. `blackCut`을 올리거나 영상 배경을 검정으로 다시 만들어요. |
| 홀로그램이 흔들려요 | 엽서를 평평한 곳에 두고 비추면 훨씬 안정적이에요. |
| 고쳤는데 그대로예요 | GitHub Pages 반영에 몇 분 걸려요. 잠시 뒤 새로고침해요. |
